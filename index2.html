Cascading Style Sheet

Cascading Style Sheets (CSS) is a style sheet language used to define the presentation and style of documents written in markup languages ​​such as HTML and XML. CSS is a fundamental technology of the World Wide Web, along with HTML and JavaScript.

CSS can control image size, body text color, table color, border size, border color, hyperlink color, mouse over color, paragraph spacing, text spacing, left, right, top, bottom margins, and other parameters.[1] CSS is a style sheet language used to control the appearance of documents.[2]

History

Currently, there are three versions of CSS: CSS1, CSS2, and CSS3. CSS1 was primarily developed for formatting HTML documents, while CSS2 was developed to address the need for document formatting for printers. CSS3, the latest version, is capable of many functions in website design. CSS3 supports content positioning, downloadable fonts, table layouts, and media types for printers. The third version of CSS is expected to be superior to the first and second versions.
